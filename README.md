# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

做一个给剧场灯光师使用的灯位与Cue表管理前端项目，可以维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和Cue触发顺序。页面需要有舞台平面灯位图、Cue列表、当前场景预览、灯具筛选和演出版本备注，适合排练期间快速调整。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62002

## 排练换角确认规则

- 执行 Cue（GO 顺序触发或单个执行）时，只核查两件事：替补/演员实际落点与期望落点偏差 **> 1.5m**、Cue 要求色片与灯具当前装片不符；任一不符即**停在当前 Cue**，舞台图、场景预览、Cue 列表同时说明原因。
- 停止只影响当前 Cue，**无关 Cue 可在列表中单独照常执行**；修正后重新执行或再按 GO 继续。
- 换角确认结果**只归本场排练**；恢复原角色后清除该角色相关判定与走位偏移，**回到基线**。
- 调整走位只**重算引用该角色的 Cue**，其他 Cue 触发顺序与灯位不变。
- 本场记录（换角、走位、实测落点、装片、判定、备注、日志）自动存 localStorage，**页面重开后保留**；「结束本场排练」一键回到基线。

## 代码分层

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 业务数据 | `src/data/` | 演出、灯具、色片、角色基线走位、Cue 顺序（只读基线） |
| 判定 | `src/domain/rules.ts` | 纯函数：偏差/色片判定、引用角色 Cue、GO 停止位计算 |
| 状态 | `src/state/` | 本场排练会话 reducer + localStorage 持久化 |
| 界面 | `src/components/` | 舞台灯位图、场景预览、Cue 列表、换角/走位面板、日志 |
